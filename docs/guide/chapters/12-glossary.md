# Glossary

| Word | Meaning |
| --- | --- |
| Action | Something a module does beyond create, edit and delete (publish, move, triage). One service, one route, one permission, one button (P84). |
| API | The server part (`api/`): data, rules, permissions. |
| Child tab | A tab on a record's page that lists other records belonging to it, using their own module's list (P86). |
| Core | The modules every product gets from the platform (users, roles, locations, …). |
| D decision | A product decision, numbered D1, D2, … in the product's log. |
| Draft | What a form holds while you type, saved on the server so it is not lost. |
| Foreign key | A column that points at a row of another table, declared in the database so a wrong value is refused. |
| Kit | This repository: the shell, its decisions, rules, components, prototype and guide. |
| Manifest | A module's `module.json` (API) and `module.ts` (web, phone): what the module is and what it offers (P81). |
| Module | One kind of thing a product manages, in one folder on every side (P80). |
| P decision | A platform decision, numbered P1 to P92, binding on every product. |
| Permission | A name like `Tasks.create` that a role grants. The menu, the route, the endpoint and the button all check the same one. |
| Prototype | The clickable copy of the product with fake data; the look every screen must match. |
| RecordLink | The component that shows a related record as a link with a preview (P85). |
| Service | One class that does one operation of a module (`TasksCreateService`) (P83). |
| Shell | Everything around a product's own screens: sign-in, sidebar, top bar, search, settings. |
| Tracker | `docs/PROGRESS.md`: where each planned step stands. |
