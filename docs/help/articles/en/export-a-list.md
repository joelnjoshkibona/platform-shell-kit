An export runs in the background, so you can keep working while it is made. When it is ready, you get a notification that opens its page, where you download it.

::: shot route=#/locations/ARU-01?tab=users
1 = main button[aria-label^="Export"]  Export: choose Excel, CSV or PDF
:::

## Start the export

1. Filter and sort the list the way you want it in the file (see [Find what you need in a list](help:find-records-in-a-list)). The export uses the same rows and columns.
2. Tap **Export** ① and choose the format. A message says the export has started.

## Download it

::: shot route=#/jobs/JOB-0041
1 = main button:has-text("Download")  Download the file
2 = main button:has-text("Run again")  Make it again with the same settings
:::

1. When the notification arrives, open it. You can also find every export under your picture, top right, in **My exports and reports**.
2. Tap **Download** ①. The page also shows the first rows and how many rows the file has.
3. Files are kept for 7 days. After that, tap **Run again** ② to make a fresh one with the same settings.

> If an export fails, its page says why in plain words. Fix the cause, then tap **Run again**.
